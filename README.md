# 📖 About the Project

Choosing the right college is often difficult due to scattered information across multiple platforms. **Edu College** solves this problem by providing a centralized platform where students can search, compare, and explore colleges while receiving personalized guidance through an AI-powered chatbot.

The application combines modern web technologies with **Generative AI** to provide a seamless, responsive, and intelligent college exploration experience.

# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/Aslaan001/Edu-College.git
```

Navigate to the project directory

```bash
cd Edu-College
```

Install dependencies

```bash
npm install
```

Create a `.env.local` file

```env
MONGODB_URI=YOUR_MONGODB_URI

NEXTAUTH_SECRET=YOUR_SECRET

NEXTAUTH_URL=http://localhost:3000

GEMINI_API_KEY=YOUR_GEMINI_API_KEY
```

Run the development server

```bash
npm run dev
```

Visit

```
http://localhost:3000
```
